Install the extension

  1. Keep the extension ZIP intact: proxy_wrangler-1.1.1.zip.
  2. In Blender, open Edit → Preferences. Open the extensions or add-ons section and choose Install from Disk from its menu. The exact menu location can vary by Blender version.
  3. Select the ZIP and install it. Enable ProxyWrangler if it is not enabled automatically.
  4. Return to the 3D Viewport. Press N to open the sidebar, then select the ProxyWrangler tab.

The panel is titled ProxyWrangler Engine. Proxy generation and manual restoration require Object Mode.

Generate proxies & dress the scene

  1. Save your scene, switch to Object Mode, and select mesh objects or collection-instance objects.
  2. Set Collapse Ratio in the ProxyWrangler panel. Start with the default 3%.
  3. Under Generate, click Selected. The new proxy objects are selected for you. All processes eligible visible assets in the active view layer, skipping assets that already have proxies.
  4. Arrange the proxies with G to move, R to rotate, and S to scale.

Proxies have names beginning with PRXY_, solid viewport display, and a wire overlay. Their geometry is baked and their materials are removed. The corresponding production assets are hidden from viewport editing.

Work on placement. Object transforms transfer to production assets. Editing proxy vertices or adding new proxy modifiers does not transfer those geometry edits to the high-poly asset.

Choose a collapse ratio

Collapse Ratio sets the percentage of geometry the decimator aims to retain. Drag the slider or enter a value from 0.1% to 100%.

SettingWhat to expect
0.1–3%Very light proxies for broad placement. Fine shapes may disappear.
3% defaultThe starting point for fast silhouette-based scene dressing.
10–30%More recognizable contours, with more geometry to draw.
100%No intended decimation reduction; useful when preserving evaluated shape matters more than polygon savings.

For example, 3% of 100,000 triangles is approximately 3,000 triangles. Actual output depends on topology, and viewport performance depends on more than polygon count.

Quality presets: Custom Ratio uses your slider exactly. Fast Layout targets 1%, Balanced targets 3%, and Detailed Silhouette targets 15%. Adaptive uses your slider and raises the ratio for smaller assets. Every mode except Custom Ratio applies the Minimum Triangles floor, which defaults to 64. Assets already below the floor retain their geometry. Final counts are approximate because collapse decimation depends on topology.

Change quality without losing placement. Select a new ratio or preset, select your proxies, then click Regenerate → Selected. Settings are saved with the scene. Existing proxies only change when you generate or regenerate.

Regenerate, select & share geometry

Each workflow row has Selected and All controls. Generate All uses visible eligible objects in the active view layer. Regenerate All and Restore Production All process proxies in the active scene; view-layer restrictions still apply. For selected regeneration or restoration, you may select a proxy or its production target.

  • Regenerate: rebuilds from the production asset using the current quality settings. The proxy object, name, placement, collection membership, and production relationship stay intact. A failed rebuild keeps the existing proxy geometry.
  • Share Matching Geometry: enabled by default. Identical evaluated geometry and quality settings can reuse one local proxy mesh while keeping separate objects and production references.
  • Safe matching: differently deformed assets use different proxy meshes. Edited cache geometry is not reused for new matches. Selected regeneration does not replace unselected proxies’ data.
  • Panel counts: compare the number of proxies with the number of unique mesh data-blocks to see sharing in action.

Shared data behaves like Blender linked duplicates. Editing vertices in a shared proxy mesh affects every proxy using that mesh. Use object transforms for layout work. Disable sharing before regeneration if you want separate proxy mesh data.

Render automatically

Click Render Preflight to check the scene without rendering. Use Preflight & Render, F12, or the ProxyWrangler entries in the Render menu for checked rendering. Ctrl + F12 and Preflight & Animation check before starting an animation render.

Preflight checks production references, duplicate mappings, local editability, missing linked libraries, collection exclusions, the active camera, and current-frame transform compatibility. The checked render action stops before starting the renderer if an issue is found. Results appear in the panel under Last preflight result.

  1. Before rendering: proxies are hidden from the render, production assets are made visible, and proxy world transforms are applied to their matching production assets.
  2. During rendering: the production geometry is used. Proxies are kept in the scene rather than deleted.
  3. After completion or cancellation: the previous production transforms and render visibility flags are restored. Production assets are hidden again in the viewport while their proxies remain available for layout work. A final visibility check runs after Blender finishes its render cleanup.

The extension enables Blender’s Lock Interface while proxies are in use to protect render-time scene updates. It restores the previous setting after all proxies are manually restored, or when the extension is disabled.

Use the checked render entry points. Native Blender Render menu actions, scripts calling Blender’s renderer directly, and render-farm commands can bypass the blocking preflight operator. Their visibility handlers still run and report detected problems, but cannot reliably cancel an already-started render. Preflight checks placement at the current frame; it does not validate every frame of an animation. Keymap conflicts may require using the panel button instead of F12.

Restore production assets permanently

Use Restore Production → Selected or All when you want to leave proxy mode.

  • Scans tagged proxies throughout the active scene; selection is not required.
  • Copies each proxy’s world-space placement to its matching production object.
  • Shows successfully restored production objects in the viewport.
  • Removes successful proxies and their unused proxy mesh data.

If an asset cannot be restored safely, its proxy is retained and a warning explains the problem. Use the same view layer that was active when the proxies were generated.

Render visibility is temporary; this button is permanent. Rendering returns you to the proxy layout. Manual restoration commits placements and removes successfully restored proxies.

Work with linked assets

ProxyWrangler supports mesh objects, collection instances, and library overrides. Proxy geometry is created locally; linked library mesh data is not edited.

  • Direct linked meshes: a local library override provides the editable production placement.
  • Linked collection hierarchies: the tool can create a local override hierarchy for selected linked members.
  • Collection instances: select the instance object to generate a combined silhouette proxy for its evaluated mesh contents, including nested mesh instances.
  • Existing overrides: local overrides carry placement changes. A selected system override may be made editable locally.

Production geometry remains linked where applicable. The local scene’s collection memberships and overrides may change to provide editable placements. Keep library files accessible when reopening a saved layout.

Troubleshooting

The buttons are disabled

Switch to Object Mode. To generate proxies, select mesh objects or collection instances in the active view layer.

The silhouette is too rough

Increase Collapse Ratio in Custom or Adaptive mode, or choose Detailed Silhouette. Select the proxies and use Regenerate → Selected. A higher percentage retains more shape detail at the cost of heavier proxies.

An asset already has a proxy

Continue working on its existing proxy, or restore production assets before generating replacements.

A production target is missing

Keep the proxy. Restore the production object or recover a saved scene containing the original relationship. Renaming a target is supported by the saved object reference, but deleting and recreating an object does not restore that relationship automatically.

Constraints, animation, or shear prevent exact placement

Check the production object’s parenting, constraints, and animated transforms. Resolve the conflicting setup and try again. Manual restoration keeps the proxy when the resulting transform does not match closely enough.

The render is missing an asset

Read the panel’s render preparation warning, confirm the linked library is available, and check collection render visibility, view-layer exclusions, and the camera. Automatic object visibility does not override all scene-level restrictions.

Restoration asks for another view layer

Switch to the view layer used during proxy generation, then use Restore Production again.

I changed the ratio but nothing changed

Use Regenerate to rebuild existing proxies. Fixed presets use their own percentages; choose Custom Ratio or Adaptive to use the slider.

Preflight reports a duplicate production mapping

Two proxies point to the same production object. Keep the intended proxy and remove the accidental duplicate. To dress multiple copies, duplicate the production placement first and generate a proxy for each copy, rather than duplicating an existing proxy.

An asset is shared across scenes

Use a separate production placement object or collection instance for each scene. Operations refuse objects shared across scenes so one scene’s layout work cannot change another scene’s production placement or visibility. Linked mesh data may still be shared between those separate placement objects.

An asset has a sheared world transform

A rotated child under a parent with nonuniform scale can produce shear. Use a placement without shear before generating proxies. The tool refuses this transform instead of creating an incorrectly shaped or positioned stand-in.
